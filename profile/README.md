This organisation is PISB's shared knowledge base: SIG material, event code, proposal archives and R&D plans, kept in one place so that every new team can **find and reuse what earlier teams built** without starting from scratch.

## 🤝 Contributing

- **One repo per SIG or code-heavy event; one folder per edition** (e.g. `ml-sig/2026/`, `xodia-credenz-2027`).
- Every repo needs a README that says what is in it, how to use it, and who built it.
- Include the **editable source** (`.pptx`, `.docx`, code), not just PDFs.
- **Never commit** registration sheets, participant data, phone numbers, personal emails, signatures, API keys or passwords.
- Ask a current PISB Tech or R&D head for write access.
