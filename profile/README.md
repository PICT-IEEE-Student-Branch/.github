PISB runs **Credenz**, our annual technical fest, along with **Credenz Tech Dayz**, the **TechRush** hackathon, and **SIGs** across ML, web, app development and programming. This organisation keeps all of it in one place: event material, SIG content and memories, so every new team can **build on what earlier teams did** without starting from scratch.

## 🤝 Contributing

- **One repo per SIG or code-heavy event, one folder per edition**: for example `ml-sig/2026/`, `credenz/2026/reverse-coding/`, `xodia-credenz-2027`.
- When you add material, change its 🔜 to ✅ here and in that repo's README.
- Include the **editable source** (`.pptx`, `.docx`, code), not just PDFs, and a short README with notes for next year's team.
- **Never commit** registration sheets, participant data, phone numbers, personal emails, API keys or passwords.
- Ask a current PISB Tech head for write access.
